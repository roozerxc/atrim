# atrim: Contributing
Welcome to atrim.

The first rule of atrim is: you do not talk about atrim

The second rule of atrim is: you DO NOT talk about atrim

Third rule of atrim: you DO NOT work on the `master` branch

Fourth rule: only work on the unstable or canary branches (those with `beta` or anything OTHER THAN `master`)

Fifth rule: if you have bugs, go document them in the issues section of the repository

Sixth rule: the code is written by someone with more than 2 braincells. No nate, no swedish sorcery, no fg discord server, no amnesia modding scene (We Have our own Now)

Seventh rule: the perseverance shall keep going as long as we must

And the eighth and final rule: if this is your first time on atrim, NEVER GIVE UP
